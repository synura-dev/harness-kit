# observe/report: bao cao tuan khai bao

- Muc = JSON trong `defaults/*.json` (id, title, source audit|candidates|ledger|inventory, filter, group_by, metric (chuoi | mang cot {as,metric,filter,rate_filter}), window_days (0 = toan thoi gian), compare prev_window|baseline, format table|kpi|list, limit, order, empty_note).
- Metric: count, sessions, per_session[:F], per_task, per_1000, sum:F, last:F, rate (rate_filter). F = `a|b.c` (truong dau co gia tri).
- Ghi de: `<project>/.harness/report/<ten>.json` (tron nong theo ten file); `{"enabled":false}` tat; file moi them muc.
- `harness observe report [--days N] [--out -|obsidian] [--dry-run] [--baseline] [--weekly] [--bootstrap-days N]`. `--weekly` (khong dry): cung chot `ledger/problems-index.json` (khoa van de high -> first/last ts, TTL 90 ngay, tran 2000, ghi atomic); ghi loi -> errors[] `cost-repeat: index_write_failed` + exit 1. `--bootstrap-days N` (1..90, sai -> loi exit 2): doc N ngay audit, chi nap index (khong dung bao cao; `--dry-run` khong ghi). Cac derive nhan `getSegments({from,to})` (cache theo cua so, segment 1 lan) + `ledger` + `onError`. Baseline: `ledger/report-baseline.json`. Obsidian: goi `harness obsidian put --section "Noi dung=..."` (qua dai/loi -> in stdout, hub tu put).
- Filter toan tu `prefix`: `{"prefix":["git status"]}` khop dau lenh hoac sau `&& `/`; `/`| ` voi ranh gioi tu (`git status --short` khop, `xgit status` khong); toi da 50 mau, so 2000 ky tu dau.
- Nguon `process`: thay doi quy trinh tu `git log` (`process-changes.mjs`, section `kpi-process-changes`: changes/tuan, so file sua lap >= 2 lan/14 ngay; ghi de paths qua `<project>/.harness/report/process-changes.json`; fail-open, `truncated: no_git|max_commits`).
- Nguon `derived`: hang do producer tinh (khong doc file). Muc khai bao `{source:"derived", derive:"<ten>", group_by, metric, ...}`; `buildReport` cap `all.derived[ten] = ({events, from, to}) => [{...}]` (`opts.derived` de test; mac dinh import lazy cac module trong `DERIVED_MODULES` cua run.mjs, moi module export `derive = {ten: fn}`; thieu module/ten -> muc rong + `empty_note`, fn throw -> muc rong + `error: derive_failed`; chi tinh khi co muc derived).
- `warnings`: nhan cot `fp` doi thanh `fingerprints`. Sua: KPI1 dung `prefix` (truoc luon 0); ms/session loc theo su kien tool (`dur_ms`), token cumulative nam trong tung cot token.
- Hang tuan: hook ledger SessionStart goi `kickReport` (<= 1 lan/7 ngay, khoa 10 phut, detached, timeout cung).
- So sanh: cot cua so lien truoc (ten theo do dai: hom qua/tuan truoc/N ngay truoc) + trung binh K cua so truoc (mac dinh K=7) + baseline. Tham so: `--avg-of K`, `--compare all|prev|avg|baseline`, config `report` (loadConfig: config/report*.json, env HARNESS_REPORT_AVG_OF/COMPARE); mac dinh trong `REPORT_DEFAULTS` (run.mjs). `--days 1` ghi `harness-daily-YYYY-MM-DD.md`. Task done lay tu ext `projects` (`projects tasks --all --json`, completed/khong tinh cancelled; fail-open).
- Dinh tuyen (T13, `routing.mjs`): 3 muc `kpi-routing`, `kpi-agy`, `routing-misses` (derive `routing_kpi|agy_kpi|routing_misses`). Lop viec tat dinh -> mode ky vong theo chinh sach (`routing-policy.mjs`; `ROUTING` o cost-contract.mjs chi la alias cua mac dinh); thieu model/out_len/phantom -> `unknown` (khong phai lech). Backend ngoai khong gia (tokens, unpriced).
  - Cau hinh: core trung tinh, mac dinh chi luat Claude (web_lookup/large_read khong co luat backend). Ghi de bang `<projectDir>/.harness/routing.json` (<= 64KB, hop nhat len mac dinh, sai schema -> mac dinh + ghi chu `routing policy: default(invalid project)` o `kpi-routing`): `{expected?:{<lop>:mode|null}, prices?:{<family>:so}, thresholds?:{largeReadChars,builderTurns,overreadChars,redoMs}, riskRe?:"regex", backends?:{<cli>:{classes:[<lop>],label?}}}`. Lop: web_lookup, large_read, plan, review (+`review_risk`), code_edit, read_small, test_run. Backend = gia tri audit `cli` (khac `claude`; du phong tien to sid `<cli>-`) la mode ky vong cua cac lop liet ke; lech -> `missed_<cli>` va `missed_external` (tong). Vi du hub (agy): `harness/observe/report/examples/hub-routing.json` (docs/ chi nhan .md).

## Muc chi phi / ngu canh / tri thuc / dinh tuyen (0.4.8)

- `kpi-cost-repeat`, `cost-by-family` (`cost-repeat.mjs`): chi phi lap lai theo khoa van de + theo ho; chi `--weekly` ghi index.
- `kpi-context-tax`, `context-dupes` (`context-tax.mjs`): token file nap san (rules, memory index, mo ta skill) + dong trung giua cac file. SKILL.md chi doc 8KB dau (mo ta), cat khong tinh la truncated.
- `kpi-knowledge`, `knowledge-roi`, `knowledge-retire` (`knowledge-roi.mjs`): ROI doc tri thuc va ung vien nghi huu; lay danh sach id qua CLI (`opts.docIds`/`opts.listIds` tiem trong test; khong tiem se spawn CLI that).
- `kpi-routing`, `kpi-agy`, `routing-misses` (`routing.mjs`): xem tren.
- Dong `truncated:` dau bao cao ghi nguon: `truncated: <muc>:<ly do>, ...` (khong trung); `events:`/`sections:` cho nguon doc chung.
- Sau khi deploy ban moi, chay mot lan: `harness observe report --bootstrap-days 28` (nap index khoa van de tu lich su).
